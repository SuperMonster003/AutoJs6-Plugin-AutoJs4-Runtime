AutoJs4 Runtime は AutoJs4 (Auto.js 4.1.1 Alpha2 のクローン) の未改変のエンジンを内蔵しており, AutoJs6 は AutoJs4 を別途インストールしなくてもこのエンジンでスクリプトを実行できます. コンソール出力は AutoJs6 に送り返されるため, 同じデバイスでスクリプトの AutoJs4 と AutoJs6 での動作を比較できます. このプラグインは主に Auto.js 4.x の旧スクリプトを移行するユーザーが実行結果を比較するためのもので, AutoJs6 で新しいスクリプトを書くだけの一般のユーザーはインストールする必要はありません.

### はじめに

1. AutoJs6 のプラグインセンターでこのプラグインが有効になっていることを確認します.
2. プラグインセンターからこのプラグインの設定を開き, "権限とサービス" でスクリプトの必要に応じて "ストレージへのアクセス", "他のアプリの上に表示" または "ユーザー補助サービス" を許可します.
3. AutoJs6 のファイルマネージャーで `.js` ファイル, `.auto` ファイルまたはプロジェクトフォルダのメニューを開き, "AutoJs4 で実行" を選びます (AutoJs6 6.8.1 以降は "AutoJs4" サブメニュー内).
4. ログは `[AutoJs4]` の接頭辞付きで AutoJs6 のコンソールに表示されます. タスクは AutoJs6 のタスク一覧に表示され, そこで停止できます.

### 主な機能

- **AutoJs4 で実行**: `.js` ファイル, `.auto` 録画ファイル, `project.json` を含むプロジェクトフォルダを AutoJs4 のエンジンで実行します. `"ui";` スクリプトの画面はこのプラグイン内に表示されます.
- **AutoJs4 で実行して比較**: 同じスクリプトを AutoJs6 と AutoJs4 でそれぞれ実行し, 2 回のコンソール出力が一致するかどうかと各実行の所要時間を "AutoJs4 比較結果" に表示します.
- **AutoJs4 コンソールウィンドウを表示**: 設定の "実行" グループにあるスイッチで, オンにすると `console.show()` で AutoJs4 のフローティングコンソールが表示されます. ログは常に AutoJs6 に送り返されます.
- **権限とサービス**: 設定にストレージへのアクセス, 他のアプリの上に表示, ユーザー補助サービス, 電池の最適化, Root 権限の状態が表示され, タップして許可または確認できます.

### スクリプトでの使い方

スクリプトは AutoJs4 の API (Auto.js 4.1.1 Alpha2 と同じ) を使います. 次のコードを `.js` ファイルとして保存して "AutoJs4 で実行" を選ぶと, コンソールの 1 行目にこのプラグインのパッケージ名が表示され, AutoJs4 で実行されたことがわかります:

```js
console.log("engine package: " + context.getPackageName());
console.log("device: " + device.brand + " " + device.model + " (API " + device.sdkInt + ")");
toast("Hello from AutoJs4");
```

- AutoJs6 にしかないモジュールや書き方は AutoJs4 では使えません. 2 つのエンジンの結果が異なるときは "AutoJs4 で実行して比較" で比較できます.
- スクリプトはこのプラグインとして実行されます. ファイルの読み書きにはこのプラグインのストレージ権限が使われ, Root 機能はデバイスの `su` を使います.
- AutoJs4 のスクリプトは同時に最大 16 個まで実行できます.

### 動作要件

- Android 7.0 以降, AutoJs6 6.8.0 以降.
- ストレージへのアクセスは, スクリプトが使うファイルの読み書きに使います.
- 他のアプリの上に表示は AutoJs4 のコンソールウィンドウとフローティング画面に, ユーザー補助サービスはウィジェットの検索や自動タップなどに使います. どちらもスクリプトが必要とするときに許可してください.
- オリジナルの AutoJs4 と同じく x86 版には OpenCV が含まれないため, x86 デバイスではそれに依存する画像機能 (画像検索など) は使えません.

### よくある質問

**権限が不足していると表示される場合**

このプラグインの権限は AutoJs6 の権限とは別です. プラグインセンターからこのプラグインの設定を開き, "権限とサービス" で表示された権限を許可してから, スクリプトを再実行してください.

**2 つのエンジンで結果が異なる場合**

このプラグインは未改変の AutoJs4 エンジンを使い, Rhino と OpenCV のバージョンも AutoJs4 と同じなので, 結果の違いは AutoJs4 と AutoJs6 の違いです. スクリプトの移行に影響する場合は [AutoJs6 の issue トラッカー](https://github.com/SuperMonster003/AutoJs6/issues) に報告できます.

**長時間実行するスクリプトがシステムに中断される場合**

このプラグインの設定の "権限とサービス" で "電池の最適化を無視" をタップし, このプラグインを電池の最適化の対象外にしてください.

AutoJs4 のスクリプト API は [AutoJs4 のドキュメント](https://github.com/SuperMonster003/AutoJs4-Documentation) を, ソースコードと詳しい説明は [プロジェクトページ](https://github.com/SuperMonster003/AutoJs6-Plugin-AutoJs4-Runtime) を参照してください.
